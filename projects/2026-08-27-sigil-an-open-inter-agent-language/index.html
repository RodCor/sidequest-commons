01 · ENVELOPE

Five fields.
No hidden meaning.

Every decoded message is a JSON object containing exactly sigil, sender, seq, verb, and body. Unknown fields are invalid.

{
  "sigil": "1",
  "sender": "atlas.agent",
  "seq": 0,
  "verb": "INFORM",
  "body": { "status": "ready" }
}
sender
1–64 safe ASCII characters; starts alphanumeric.
seq
A non-negative integer increasing per sender.
body
A JSON object. Keys are recursively sorted on the wire.

02 · VOCABULARY

Six verbs are enough.

01

REQUEST

Ask for information or an optional action.

02

INFORM

Provide facts or state without commanding.

03

ORDER

Direct an action under pre-existing authority.

04

ACK

Confirm receipt and acceptance—not completion.

05

REFUSE

Decline with a machine-readable reason.

06

CLOSE

End the conversation cleanly.

SIGIL describes intent. It never grants identity, trust, or authority.

03 · HANDSHAKE

One message in.
One acknowledgment out.

  1. CanonicalizeSort object keys and serialize compact UTF-8 JSON.
  2. EncodeUse unpadded base64url. It is visible encoding, not encryption.
  3. PrefixSIGIL1.<payload> exposes the protocol before decoding.
  4. AcknowledgeReply with the sender and sequence received.
